Projects (Authenticated)

All project endpoints require Authorization: Bearer <token> header.

MethodPathDescription
GET/api/projectsList user's projects
POST/api/projectsCreate a new project
GET/api/projects/:idGet project details
DELETE/api/projects/:idDelete a project

Create Project

POST /api/projects
Authorization: Bearer <token>
{
  "name": "My API",
  "gitUrl": "https://github.com/user/repo.git"  // optional
}

201 Response:
{
  "project": {
    "id": "uuid",
    "name": "My API",
    "gitUrl": null,
    "status": "ready",
    "sandboxPath": "/path/to/sandbox",
    "createdAt": "2026-06-08T00:00:00.000Z",
    "updatedAt": "2026-06-08T00:00:00.000Z"
  }
}

List Projects

GET /api/projects
Authorization: Bearer <token>

200 Response:
{
  "projects": [
    {
      "id": "uuid",
      "name": "My API",
      "gitUrl": null,
      "status": "ready",
      "createdAt": "2026-06-08 00:00:00",
      "updatedAt": "2026-06-08 00:00:00"
    }
  ]
}

Goals (Authenticated)

MethodPathDescription
POST/api/projects/:id/goalsSubmit a new goal
GET/api/projects/:id/goalsList goals for a project
GET/api/projects/:id/goals/:gidGet goal status
GET/api/projects/:id/goals/:gid/streamSSE event stream
POST/api/projects/:id/goals/:gid/steerSend steering action
GET/api/projects/:id/goals/:gid/messagesGet persisted message history

Submit a Goal

POST /api/projects/:id/goals
Authorization: Bearer <token>
{
  "goal": "Build a REST API for a todo app"
}

202 Response:
{
  "goal": { "id": "uuid", "status": "planning", ... }
}

SSE Stream

GET /api/projects/:id/goals/:gid/stream
Authorization: Bearer <token>

Fetched via fetch() + ReadableStream (not native EventSource)
because we need to set the Authorization header.

Events:
  event: status_change   { status, message }
  event: plan_ready       { plan: [{step, description, files}], totalSteps }
  event: steering_needed  { prompt, options: [{label, action}] }
  event: step_start       { step, description, files }
  event: step_complete    { step, success, summary }
  event: user_message     { text }
  event: done             { status, message }
  event: error            { message }

Steer a Goal

POST /api/projects/:id/goals/:gid/steer
Authorization: Bearer <token>
{
  "action": "approve" // approve | regenerate | stop | message | redo | skip
}

// For 'message' action, include payload:
{
  "action": "message",
  "payload": { "text": "Try using Express instead of Hono" }
}

200 Response: { "ok": true, "status": "executing" }

Files (Authenticated)

MethodPathDescription
GET/api/projects/:id/filesRecursive file tree
GET/api/projects/:id/files/*File content (text or base64)

File Tree

GET /api/projects/:id/files
Authorization: Bearer <token>

200 Response:
{
  "tree": [
    { "name": "src", "type": "directory", "children": [
      { "name": "index.ts", "type": "file", "path": "src/index.ts" }
    ]}
  ]
}
// Skips .git and node_modules directories

File Content

GET /api/projects/:id/files/src/index.ts
Authorization: Bearer <token>

200 Response (text):
{ "content": "console.log('hello')\n", "encoding": "utf8" }

      200 Response (binary):
{ "content": "iVBORw0KGgo...", "encoding": "base64" }

Preview (Public — No Auth)

Static files from sandbox or proxied dev server. No auth required — project UUIDs serve as unguessable access keys.

MethodPathDescription
GET/api/preview/:projectIdAuto-detect index.html or dev server root
GET/api/preview/:projectId/*Serve specific file (static or proxied)

If the project has a package.json with a dev or start script, the backend auto-starts npm install && npm run dev and proxies requests. HTML responses have absolute paths rewritten (/assets/* → /api/preview/:projectId/assets/*) so framework assets resolve correctly.
