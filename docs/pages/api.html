API Reference

REST API endpoints for the Storm backend

Health

MethodPathDescription
GET/api/healthServer health check
 
{
  "healthy": true,
  "version": "0.1.0"
}

Auth

MethodPathDescription
POST/api/auth/registerCreate a new account
POST/api/auth/loginLogin and get JWT token

Register

POST /api/auth/register
{
  "email": "user@example.com",
  "password": "securepassword"
}

201 Response:
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": { "id": "uuid", "email": "user@example.com" }
}

Login

POST /api/auth/login
{
  "email": "user@example.com",
  "password": "securepassword"
}

200 Response:
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": { "id": "uuid", "email": "user@example.com" }
}

Projects (Authenticated)

All project endpoints require Authorization: Bearer <token> header.

MethodPathDescription
GET/api/projectsList user's projects
POST/api/projectsCreate a new project
GET/api/projects/:idGet project details
DELETE/api/projects/:idDelete a project

Create Project

POST /api/projects
Authorization: Bearer <token>
{
  "name": "My API",
  "gitUrl": "https://github.com/user/repo.git"  // optional
}

201 Response:
{
  "project": {
    "id": "uuid",
    "name": "My API",
    "gitUrl": null,
    "status": "ready",
    "sandboxPath": "/path/to/sandbox",
    "createdAt": "2026-06-08T00:00:00.000Z",
    "updatedAt": "2026-06-08T00:00:00.000Z"
  }
}

List Projects

GET /api/projects
Authorization: Bearer <token>

200 Response:
{
  "projects": [
    {
      "id": "uuid",
      "name": "My API",
      "gitUrl": null,
      "status": "ready",
      "createdAt": "2026-06-08 00:00:00",
      "updatedAt": "2026-06-08 00:00:00"
    }
  ]
}
