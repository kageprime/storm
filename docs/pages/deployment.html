Deployment

Deploying Storm on DigitalOcean

Prerequisites

  • DigitalOcean Droplet (4GB RAM, 2 vCPUs, Ubuntu 24.04)
  • Domain name pointed to droplet IP
  • Docker and Docker Compose installed on droplet

Quick Start

# Clone the repo on the droplet
git clone https://github.com/your-org/storm /opt/storm
cd /opt/storm

# Create required directories
mkdir -p data/sandboxes

# Build frontend
cd web && npm install && npm run build && cd ..

# Build and start
docker compose up -d

# Check logs
docker compose logs -f

Prerequisites: opencode Server

The opencode server must be running on port 4096 (or the port specified by OPCODE_URL). The backend does not spawn it — you must run it separately:

# Install opencode
npm install -g @opencode-ai/cli

# Start the server
opencode serve --port 4096
