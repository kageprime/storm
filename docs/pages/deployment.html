Deployment

Deploying Storm on DigitalOcean

Prerequisites

  • DigitalOcean Droplet (4GB RAM, 2 vCPUs, Ubuntu 24.04)
  • Domain name pointed to droplet IP
  • Docker and Docker Compose installed on droplet

Production Architecture

Internet | v +----------------------------+ | Caddy (reverse proxy) | | :443 (HTTPS) + :80 (redirect) | | Auto TLS via Let's Encrypt | +------------+---------------+ | v +----------------------------+ | storm-server (Docker) | | :3000 (internal) | | | | +----------------------+ | | | Hono + opencode SDK | | | +----------------------+ | | +----------------------+ | | | SQLite (volume) | | | +----------------------+ | +----------------------------+ | v +----------------------------+ | Sandbox directories | | /data/sandboxes/ | | (Docker volume) | +----------------------------+

Quick Start

# Clone the repo on the droplet
git clone https://github.com/your-org/storm /opt/storm
cd /opt/storm

# Create required directories
mkdir -p data/sandboxes

# Build and start
docker compose up -d

# Check logs
docker compose logs -f
