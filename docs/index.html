Key Features

What makes Storm different

Autonomous Agent Loop

Goal → Plan → User approves → Execute steps → User steers → Complete. The agent breaks down high-level goals into actionable sub-tasks.

Real-time Streaming

Watch the agent work live via SSE — every step summary, status change, and completion event streams to the browser as it happens.

Live File Preview

Browse the sandbox file tree and preview any file — HTML renders in a sandboxed iframe, images display inline, code gets syntax-highlighted.

User Steering

At every decision point — plan review, step completion, errors — the user can approve, modify, retry, or redirect via chat or buttons.

Free DeepSeek Model

Powered by opencode/deepseek-v4-flash-free — no API key needed, no costs, built directly into opencode.

Sandboxed Execution

Each project runs in an isolated filesystem directory. opencode operates only within its sandbox. Docker isolation coming in Phase 2.

Message History

Every goal conversation — including plans, step results, steering actions, and user messages — is persisted and reloaded on reconnect.

Hosted Service

Multi-user, accessible from anywhere via browser. JWT auth, project management, and full API for integrations.
